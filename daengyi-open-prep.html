댕이를 부탁해 · 오픈 준비 안내

서비스 오픈 전, 사장님이 준비하실 것

플랫폼 개발은 마무리 단계입니다. 실제 결제를 받고 정식 오픈하려면 사업자 관련 서류와 도메인이 필요합니다. 아래 순서대로 진행하시면 됩니다.

미팅 2026. 09. 03 대상 애견호텔 · 데이케어 + 온라인 쇼핑몰 통합 플랫폼
완료플랫폼 개발 (예약·쇼핑몰·결제·관리자)
8사장님 준비 항목
2~3주사업자등록 처리 후 오픈까지
완료됨 사장님이 준비 개발사가 처리
01

이미 만들어진 것

사장님 확인 없이도 지금 바로 시연 가능한 기능입니다.

  • 예약 시스템 — 호텔 숙박 / 데이케어, 날짜·시간 선택, 정원 관리
  • 쇼핑몰 — 상품·카테고리·장바구니·주문
  • 결제 — 토스페이먼츠 카드·카카오페이 (현재 테스트 모드)
  • 회원 — 이메일 가입 + 카카오 로그인
  • 마이페이지 — 예약·주문·문의 내역, 배송조회
  • 관리자 페이지 — 대시보드, 예약·상품·주문·회원·문의 관리, 송장 등록
  • 디자인 테마 2종 — 메인화면 포함, 관리자에서 전환
  • 1:1 문의 — 접수 및 답변
  • 이용약관 · 개인정보처리방침 — 초안 작성 (사업자 정보만 채우면 완성)
02

사장님이 준비하실 것

번호는 진행 순서입니다. ①이 되어야 ④·⑤가 진행됩니다.

1

사업자등록

진행 중
왜
결제 정산·통신판매·세금의 기본. 아래 대부분이 이 번호에 달려 있습니다.
준비
개인사업자 등록 — 업종에 애견호텔업(동물위탁관리업)과 전자상거래 소매업(통신판매)을 함께 넣기
어디서
홈택스 온라인 신청 또는 관할 세무서 (보통 2~3일)
2

통신판매업 신고

대기
왜
온라인 상품 판매의 법적 필수 절차. 토스 가맹점 심사에도 신고번호가 필요합니다.
준비
사업자등록증 + 구매안전서비스 이용확인증(에스크로 — 결제대행사/은행에서 발급)
어디서
정부24 또는 관할 시·군·구청
3

사업자 정보 전달

대기
왜
약관·개인정보처리방침·사이트 하단·결제 화면에 표시됩니다. 결제 심사 통과 조건이기도 합니다.
전달할 값
상호명 · 대표자 성명 · 사업자등록번호 · 통신판매업 신고번호 · 사업장 주소 · 대표 전화 · 대표 이메일 · 개인정보 보호책임자
정하실 것
예약 취소·환불 규정(기간별 환불 비율) · 배송비 정책 · 교환/반품 규정
4

토스페이먼츠 가맹점(정산) 심사

1·2번 후
왜
실제 결제 대금을 정산받으려면 필수. 지금은 테스트 결제만 됩니다.
서류
사업자등록증 · 통신판매업 신고증 · 대표자 신분증 · 정산받을 통장 사본
참고
심사 시 사이트에 약관·사업자정보·환불정책이 표시돼 있어야 통과. 통과 후 개발사가 테스트키 → 실제(라이브)키로 교체.
5

카카오 로그인 — 비즈니스 인증

1번 후
왜
카카오 로그인으로 이메일까지 받으려면 카카오 비즈니스 인증이 필요합니다. (현재는 닉네임만 수집)
준비
카카오 디벨로퍼스에서 사업자등록번호로 비즈니스 인증 신청
참고
로그인 기능·앱 설정은 이미 완료. 인증만 하면 이메일 동의항목이 활성화됩니다.
6

도메인 구매

대기
왜
사이트 실제 주소(예: daengyi.co.kr). 사업자번호 없이 개인으로도 구매 가능합니다.
어디서
가비아 · 후이즈 · 카페24 · Cloudflare 등 — 연 2만 원 안팎, .co.kr 권장
정하실 것
원하는 주소 후보 2~3개. 구매 후 개발사에 계정 정보 전달.
7

이메일 발송 도메인 인증 (Resend)

6번 후
왜
가입 인증·예약/주문 알림 메일을 사장님 도메인 주소로 보내기 위함.
준비
도메인 구매 후 Resend가 안내하는 DNS 값 등록 (개발사가 값 전달·확인)
8

사업용 계좌 · 결제수단

선택
왜
정산 통장, 도메인·호스팅 등 소액 비용 결제용. 개인 계좌로도 시작 가능하나 사업용 분리 권장.
03

개발사가 처리할 것

사장님 액션은 없습니다. 재료(사업자 정보·도메인·라이브키)가 준비되면 진행합니다.

·

실서버 배포 & 도메인 연결

내용
클라우드(Vercel/Netlify)에 배포, 구매한 도메인 연결, HTTPS 적용
·

키 · 환경설정 이전

내용
API 키 이전, 토스 라이브키 교체, Supabase 운영 설정(이메일 인증 재활성화), 카카오 Redirect URI에 실도메인 추가
·

마무리 기능

내용
회원가입 약관 동의 체크박스, 예약·주문 완료 알림 메일 연동, 최종 점검
04

오픈까지 순서

사업자등록·심사 처리 기간에 따라 앞뒤로 움직일 수 있습니다.

1주차
사장님사업자등록 → 통신판매업 신고
개발사사업자 정보 받는 대로 약관·개인정보처리방침 완성
2주차
사장님토스 가맹점 심사 신청 · 카카오 비즈니스 인증 (동시 진행)
사장님도메인 구매 → 개발사 전달
3주차
개발사실서버 배포 · 도메인 연결 · 라이브키 교체 · Resend 도메인 인증
개발사전체 흐름 최종 점검 → 정식 오픈
지금 당장 하실 것 — ① 사업자등록 완료(진행 중), ② 통신판매업 신고, ③ 사업자 정보 전달, ⑥ 도메인 후보 정하기. 이 4가지가 나머지 일정을 결정합니다.
